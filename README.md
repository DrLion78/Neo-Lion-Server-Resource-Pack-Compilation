# Deploying

You will want to use Merged. It is unzip so if you're sharing this or having this be in a Minecraft server, be sure to zip up this folder. It doesn't have to be called, “Merge”. It can be other names.

As for zipping the folder, only the contents inside `Merge` should be in the zip folder, don't merge `Merge` folder itself.

Also, don't forget to credit me for the resource pack compilation if you are using it itself or in part of your resource packs.
